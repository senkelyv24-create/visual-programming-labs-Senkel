# visual-programming-labs-Senkel

Репозиторий лабораторных работ по курсу **Технологии визуального программирования** (ГрГУ, Сенкель Я.В.).

## Структура

- `lab1/` — лабораторная работа №1: моделирование процесса с Git и визуальными нотациями (BPMN, UML Activity, Sequence, Flowchart). Тема: бронирование номера в отеле.
- `lab2/` — лабораторная работа №2: Node-RED. Потоки в `lab2/flows/`, описание API в `lab2/docs/api.md`, отчёт в `lab2/docs/report.md`. Запуск: `npm install` и `npm start` в папке `lab2` (редактор на http://localhost:1880).
