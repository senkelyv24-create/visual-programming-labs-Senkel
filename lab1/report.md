# Отчёт по лабораторной работе №1

## Процесс
Тема: **бронирование номера в отеле**. Гость выбирает даты и тип номера, система проверяет доступность, считает стоимость, принимает оплату; при успехе бронь создаётся, ресепшен готовит номер, гость получает подтверждение. Есть два ветвления (доступность и результат оплаты) и параллельные действия после успешной оплаты.

## Diff текстовых и бинарных файлов
После мелкого изменения BPMN (добавлена задача «Отправить SMS-напоминание») `git diff` по `.bpmn` показывает конкретные XML-строки. Для PNG Git пишет только, что бинарные файлы отличаются, без построчного diff. В Mermaid- и draw.io-файлах изменения тоже читаются как обычный текст.

## Выводы
На практике видно, что текстовые форматы (BPMN XML, Mermaid, draw.io XML) удобны для версионирования: в истории коммитов видно, что именно поменялось. PNG удобны для отчёта и защиты, но для сравнения версий почти бесполезны. Git с осмысленными коммитами помогает восстановить шаги работы и показать преподавателю ход выполнения лабораторной.
