## 1. Что сделано

Трек **TypeBot**. Тема бота продолжает третью лабораторную: каталог «Зелёный подоконник». За основу взят короткий англоязычный сценарий сбора обращения (приветствие, имя, email, кнопки Watering / Light / Repotting, подробности, прощание). Его экспорт: [exports/flow-01-template-original.json](../exports/flow-01-template-original.json).

Дальше сценарий переведён на русский и дополнен. Итоговый бот называется `lab5-Сенкель Зелёный подоконник`. Экспорт: [exports/flow-02-zelenyy-podokonnik-ru.json](../exports/flow-02-zelenyy-podokonnik-ru.json).

Схема после доработки:

```text
Приветствие → Имя → Погода (HTTP) → Задача
  → Дни без полива
      → [Condition: Дни > 7] → Режим: полить ─┐
      → [иначе]              → Режим: подождать ┴→ Email → Подробности → Итог
```

Переменную `Name` я переименовал в `Имя` и заменил все вставки `{{Name}}` на `{{Имя}}`. `{{Email}}` осталась как была, чтобы проверка почты не разъехалась с текстом.

## 2. Запуск

В условии TypeBot можно поднять у себя через Docker. На этом компьютере Docker нет, как и во второй и четвёртой работах, поэтому контейнеры я не запускал. Файл [docker-compose.yml](../docker-compose.yml) написан по треку C: builder на `http://localhost:8080`, viewer на `http://127.0.0.1:8081` (другое имя хоста, иначе cookie ломают предпросмотр), PostgreSQL и Mailpit для входа по письму. Секрет кладётся в `.env` из [.env.example](../.env.example), сам `.env` в репозиторий не входит.

Сам бот я собрал в Typebot Cloud: импортировал оба JSON и опубликовал русский сценарий. Публичная ссылка: https://typebot.co/lab5-u0rfp2a. Снимки экрана лежат в [screenshots](../screenshots).

## 4. Что добавлено сверх шаблона

| Требование | Что сделано |
| --- | --- |
| Минимум 2 новых шага | Четыре новые группы: «Погода (HTTP)», «Дни без полива», «Режим: полить», «Режим: подождать» |

Проверка веток без редактора, 20 ноября 2026. Запрос к Open-Meteo вернул `temperature_2m = 2.1`.

## 6. Блоки

* **Bubbles:** Text.
* **Inputs:** Buttons (choice input), Text, Email с текстом ошибки, Number.
* **Logic:** Condition, Set variable.
* **Integrations:** Webhook, поле ответа `data.current.temperature_2m` пишется в переменную.
* **Прочее:** переменные `{{...}}`, группы и связи, Theme, Settings (брендинг и описание), экспорт JSON.

## 7. Вывод

В Typebot сценарий собирается из групп: текст, ввод, условие и HTTP-запрос видны на одной схеме. Условие по дням без полива уводит диалог в одну из двух веток, Set variable запоминает режим, и в последнем сообщении подставляются имя, задача, дни, режим и email. Это я проверил на опубликованной ссылке https://typebot.co/lab5-u0rfp2a: 10 дней дали «полить сегодня», в текст попали имя, погода из Open-Meteo и email. Docker на компьютере по-прежнему нет, локальный стек не запускался. На бесплатном плане облака подпись Made with Typebot не выключается, хотя в экспорте брендинг выключен. Шрифт Nunito и зелёные цвета на живом чате есть. Снимки редактора, темы, условия, переменной и готового диалога лежат в `lab5/screenshots`.
