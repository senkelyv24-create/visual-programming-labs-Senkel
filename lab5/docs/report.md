## 1. Что сделано

Трек **TypeBot**. Тема бота продолжает третью лабораторную: каталог «Зелёный подоконник». За основу взят короткий англоязычный сценарий сбора обращения (приветствие, имя, email, кнопки Watering / Light / Repotting, подробности, прощание). Его экспорт: [exports/flow-01-template-original.json](../exports/flow-01-template-original.json).

Дальше сценарий переведён на русский и дополнен. Итоговый бот называется `lab5-Сенкель Зелёный подоконник`. Экспорт: [exports/flow-02-zelenyy-podokonnik-ru.json](../exports/flow-02-zelenyy-podokonnik-ru.json).

Схема после доработки:

```text
Приветствие → Имя → Погода (HTTP) → Задача
  → Дни без полива
      → [Condition: Дни > 7] → Режим: полить ─┐
      → [иначе]              → Режим: подождать ┴→ Email → Подробности → Итог
```

Переменную `Name` я переименовал в `Имя` и заменил все вставки `{{Name}}` на `{{Имя}}`. `{{Email}}` осталась как была, чтобы проверка почты не разъехалась с текстом.

## 2. Запуск

В условии TypeBot можно поднять у себя через Docker. На этом компьютере Docker нет, как и во второй и четвёртой работах, поэтому контейнеры я не запускал и скриншоты редактора не рисовал. Файл [docker-compose.yml](../docker-compose.yml) написан по треку C: builder на `http://localhost:8080`, viewer на `http://127.0.0.1:8081` (другое имя хоста, иначе cookie ломают предпросмотр), PostgreSQL и Mailpit для входа по письму. Секрет кладётся в `.env` из [.env.example](../.env.example), сам `.env` в репозиторий не входит.

Когда Docker будет, из папки `lab5`: скопировать `.env.example` в `.env`, вписать секрет из 32 символов, затем `docker compose up -d`. В редакторе: Import → файл `flow-02-zelenyy-podokonnik-ru.json` → Publish. Ссылка будет локальной, на машине, где запущен viewer.

## 6. Блоки

* **Bubbles:** Text.
* **Inputs:** Buttons (choice input), Text, Email с текстом ошибки, Number.
* **Logic:** Condition, Set variable.
* **Integrations:** Webhook, поле ответа `data.current.temperature_2m` пишется в переменную.
* **Прочее:** переменные `{{...}}`, группы и связи, Theme, Settings (брендинг и описание), экспорт JSON.

## 7. Вывод

В Typebot сценарий собирается из групп: текст, ввод, условие и HTTP-запрос видны на одной схеме, а ответы должны попадать в Results после публикации. Условие по дням без полива уводит диалог в одну из двух веток, Set variable запоминает режим, и в последнем сообщении подставляются имя, задача, дни и email. Сложнее всего здесь не блоки, а запуск: без Docker редактор и web-ссылку не поднять, поэтому в репозитории лежат оба экспорта и compose-файл, а не снимки чужого интерфейса. На защите бота можно открыть импортом `flow-02` либо показать две ветки из таблицы выше: 10 дней дают «полить сегодня», 3 дня — «полив не срочный».
